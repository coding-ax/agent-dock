Agent logos identify the ACPX built-in agents in AgentDock. Most SVGs come from
[Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg` 1.95.1 (MIT). In particular, `gemini.svg` is the
Gemini CLI mark, `mcode.svg` is MiniMax, `poolside.svg` is Poolside, and
`grok.svg` is Grok. The existing `deepseek.svg` also comes from Lobe Icons.

The remaining marks come from their projects:

- `droid.svg`: [Factory favicon](https://www.factory.ai/favicon.svg)
- `fast-agent.svg`: [fast-agent icon](https://github.com/evalstate/fast-agent/blob/main/docs/docs/assets/brand/fast-agent-icon.svg)
- `iflow.png`: [iFlow CLI favicon](https://platform.iflow.cn/img/favicon.ico)
- `mux.svg`: [Mux favicon](https://github.com/coder/cmux/blob/main/docs/favicon.svg)
- `zeroclaw.svg`: [ZeroClaw app icon](https://github.com/zeroclaw-labs/zeroclaw/blob/master/apps/tauri/icons/icon.svg)

Unknown custom Agent IDs use the generic Lucide Bot icon.
