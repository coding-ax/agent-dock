# AgentDock Web 界面重做：目标、任务与验收标准

> 写给接手执行的 Agent。每个任务都写了「改什么」「做到什么程度」「怎么验证」。
> 不要自己发挥风格：视觉方向已经和用户确认过，按本文执行。拿不准的地方停下来问用户，不要猜。

## 0. 背景

用户对当前界面的反馈，按原话归纳：

- 整体太丑、看久了累。主区和侧栏都是灰的，没有主流 Agent 客户端「侧栏浅灰、对话区纯白」的层次。
- 吉祥物（发光机器人、线条机器人）都很丑。强调色和背景自定义「根本没必要」。
- 对话面板的思考和工具步骤不够灵动；loading 形态太多太杂。
- 飞书配置第二步里，「群聊主流消息的会话隔离」这一行布局错位。
- 之前的部分功能设计不合理：侧栏会话重复出现，标题栏都是看不懂的图标，输入框底栏信息不清。

用户已确认的决定：

1. 侧栏会话**默认按时间分组**。
2. 吉祥物改成**简单的矢量线条小猫**：单色、不要彩色，眼睛和神态跟着鼠标走。
3. 其余按本文方案执行。

参考对象（只借鉴模式，不抄素材）：Vercel `ai-elements`（Reasoning / Tool / Chain of Thought / Shimmer）、assistant-ui、LobeChat，以及 ChatGPT、Claude、Codex 桌面端的通行做法。

## 1. 总目标

把 AgentDock Web 端做成**专业、克制、长时间看不累**的 Agent 工作台：

- 浅色：侧栏浅灰、对话区纯白；暗色：侧栏更深、对话区稍浅，两版层次一致。
- 对话面板按 Agent 输出顺序展示步骤链，运行中只有一种 loading 语言，完成后整轮折叠。
- 去掉所有装饰性元素（发光、渐变光晕、极光背景、自定义强调色），只保留一只单色线条小猫作为形象。
- 修正侧栏、标题栏、输入框、设置、飞书表单里不合理的交互。

## 2. 工作约束（必须遵守）

- **代码基线**：当前分支 `coding-ax/refactor-agent-dock-chat`，工作区有约 45 个未提交改动，是上一轮重构的成果。在它上面继续改，不要回滚，不要用裸 `git stash`。提交时机听用户指示，默认不提交。
- **不许动正式 daemon**：禁止 `agent-dock restart/stop/update`、`npm install -g`、kill 4310 上的进程。见仓库 `AGENTS.md`。
- **本地预览**：4311 端口已有 Vite 开发服务（`/api` 代理到正式 daemon 4310，用的是真实数据），改代码会热更新。如果它不在了，用下面的命令重启：
  ```bash
  cd apps/web && nohup pnpm exec vite --host 127.0.0.1 --port 4311 > /tmp/agentdock-web-dev.log 2>&1 &
  ```
  确认 `vite.config` 里的代理目标是 4310 再启动。
- **真实数据保护**：4311 连的是用户真实数据。验证时**不要**点任何会写入的按钮：保存、归档、删除、发送消息、飞书配置里的「下一步」或标签切换后的保存。要验证写入流程，用 `node apps/server/dist/cli.js dev up` 起隔离沙箱，用完 `dev down`。
- **浏览器只用 ego-browser**：开始前运行 `ego-browser skill` 并读到 `[ego-browser:skill] end of guide`。整个任务只建一个 TaskSpace，复用 `spaceId`。禁止 Playwright、Puppeteer 或无头 Chromium。
- **每个任务结束都要跑**：
  ```bash
  pnpm --filter ./apps/web exec tsc --noEmit   # 或仓库根目录 pnpm typecheck
  pnpm --filter ./apps/web exec vitest run
  ```
  全部通过才算完成。测试因行为变化失败时，更新测试并在汇报里说明原因，不要删测试凑通过。
- **截图规范**：每个任务验收截两张图，浅色和暗色各一张，视口 1440×900，存到 `/tmp/agentdock-ui/<任务编号>-<light|dark>.png`。汇报时列出路径。
- **减少动态效果**：所有新动画在 `prefers-reduced-motion: reduce` 下必须关闭或降为纯淡入。

## 3. 设计规格（所有任务共用）

### 3.1 颜色变量

改 `apps/web/src/index.css` 里 `:root` 和 `:root[data-theme="dark"]` 的变量。变量名保持不变，业务 class 不用逐个改。

| 变量 | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| `--rail` | `#f9f9f9`（249 249 249） | `#171717`（23 23 23） | 侧栏底色 |
| `--bg` | `#ffffff` | `#212121`（33 33 33） | 主区（对话区）底色 |
| `--surface`（即 `bg-white`） | `#ffffff` | `#2a2a2a`（42 42 42） | 卡片、弹窗、输入框 |
| 边框（`zinc-200`） | `#ececec` | `#333333` | 分隔线、卡片边框 |
| 正文（`zinc-900`） | `#0d0d0d` | `#ececec` | 正文文字 |
| 次要文字（`zinc-500`） | `#6b6b6b` | `#9b9b9b` | 说明、时间、元信息 |
| 选中 / 悬停（`zinc-100`） | `#ececec` | `#2f2f2f` | 侧栏选中行、悬停底 |
| `--accent` | 等于正文色 | 等于正文色 | 不再用紫色。主按钮浅色下黑底白字，暗色下白底黑字 |
| `--link` | `#2563eb` | `#7aa7ff` | 链接 |

- 其余 zinc 阶按上表插值，保证从 50 到 950 单调递变。
- 红、黄、绿、蓝的 50/100/200 浅色阶在暗色下保持现有处理，文字对比度不低于 4.5:1。
- **整个界面只有 Logo 允许出现紫色。** 用 `grep -rn "violet\|purple\|accent" apps/web/src` 检查，除 Logo 外的紫色都要去掉。

### 3.2 字体与字号

- 字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Segoe UI", "Helvetica Neue", "Microsoft YaHei", sans-serif`。去掉 `tailwind.config.js` 里没有加载的 `Inter`。等宽字体保持 `SFMono-Regular, ui-monospace, Menlo, monospace`。
- Agent 正文和用户消息：15px，行高 1.7。
- 步骤行（思考、工具、已处理）：13px。
- 元信息（耗时、计数、副标题）：12px。
- **全站最小字号 12px。** 完成后 `grep -rn "text-\[10px\]\|text-\[11px\]" apps/web/src` 应该为 0 处，或只剩有书面理由的例外（例如计数徽标），汇报时逐条列出例外。

### 3.3 动效

- 统一时长 150–220ms，曲线 `cubic-bezier(.2, 0, 0, 1)`（ease-out）。**不用弹性回弹**，即不用 `cubic-bezier(.34, 1.56, …)` 这类超调曲线；吉祥物除外。
- 展开和收起用 `grid-template-rows: 0fr → 1fr` 加 opacity 过渡，不要瞬间出现。
- 新出现的步骤：opacity 0→1 加 translateY 4px→0。
- 按钮按压只做 `scale(.97)`。
- 删掉现有的弹性弹窗入场，改成 opacity 加 `scale(.98→1)`。

### 3.4 统一的 loading 语言

整个站只保留三种：

1. **扫光文字**（`ui-shimmer-text`）：表示「正在进行的这一步」，用在思考标题、工具行、处理中提示。
2. **小转圈**：14px 细线圆环，表示按钮或控件在等待。
3. **骨架屏**：灰块加扫光，表示首屏数据加载。

删掉 `BrailleSpinner`、`TypingDots`、`ScannerBar`、`AsciiProgress`，以及 Knight Rider 扫描条。`TopProgressBar` 可以保留，但颜色改成正文色，高度 2px。

### T8 空状态与线条小猫

**改动**（重写 `DockMascot.tsx`，删掉 `index.css` 里 `.ui-mascot*` 的旧规则后重写；修改 `App.tsx` 的空状态）

**小猫设计规格**

- **纯 SVG 线条**：`stroke="currentColor"`，线宽 1.75px（按 96px 尺寸算），`stroke-linecap/linejoin: round`，**不填色**。只有眼珠允许实心填充，也用 currentColor。
- 颜色跟随正文色（浅色下近黑，暗色下近白）。**不出现任何彩色，不发光，不用渐变。**
- **造型**：正面坐姿的小猫。
  - 头部是一个圆润的圆角形，两只三角形耳朵，耳尖略圆。
  - 两只眼睛是圆形眼眶，里面有可以移动的实心眼珠。
  - 一个小小的倒三角鼻子，加一张「ω」形的嘴。
  - 两侧各两根胡须。
  - 身体是一个简单的弧线轮廓，两只前爪是两个小半圆。
  - 尾巴是一条从身后绕到侧面的曲线。
  - 整体在 96×96 的 viewBox 里，线条不超过 15 条路径，保持简洁。
- **眼神跟随**：
  - 眼珠在眼眶内跟随鼠标移动，最大偏移是眼眶半径的 45%。
  - 头部跟随鼠标做 ±3px 的平移和 ±4° 的倾斜，耳朵跟着动。
  - 用 `pointermove` 加 `requestAnimationFrame` 更新 CSS 变量，**不触发 React 重渲染**（沿用现有做法）。
  - 鼠标离开窗口 1.5 秒后，眼睛慢慢回到正中。
- **神态**：
  - 待机时每 4–7 秒随机眨一次眼，眼眶 scaleY 变成 0.1，持续 120ms。
  - 尾巴缓慢摆动，周期 3 秒，幅度 ±8°。
  - 鼠标悬停时眼睛变成「^ ^」弯眼，胡须轻轻上扬。
  - 鼠标长时间（10 秒）不动时眼睛半闭，像犯困；鼠标一动就醒。
  - 点击时耳朵抖一下，持续 300ms。不要整体弹跳。
  - 用户在输入框打字时，眼珠看向输入框方向（向下），每次按键耳朵微动一下。
- **减少动态效果**：只保留静态造型，眼睛居中。
- **尺寸**：空状态里 88px。不要在其他地方使用小猫。

**空状态布局**

- 页面纵向居中：小猫 → 16px → 标题「有什么要做的？」（22px、600 字重）→ 24px → 输入框（最大宽度 720px）。

- 删掉副标题「在同一个工作台中运行 Codex、Claude……」和背后的光晕。

**完成条件**

- SVG 里没有 `fill` 彩色值，也没有 `filter`、`gradient`、`<image>`。用 `grep -n "gradient\|filter\|#[0-9a-f]\{3,6\}" apps/web/src/DockMascot.tsx` 检查，结果应该为空。
- 浅色、暗色下小猫都清晰可见，线条颜色就是正文色。
- 眼神跟随、眨眼、悬停弯眼、犯困、打字时看向输入框，五个状态都截到图。
